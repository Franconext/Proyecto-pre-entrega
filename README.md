# 📦 Proyecto Pre-Entrega

Proyecto desarrollado como pre-entrega de un curso de **Node.js** de Talento tech. La aplicación corre directamente en Node.js sin dependencias externas, con lógica implementada en un único archivo principal.

---

## 🚀 Tecnologías utilizadas

- [Node.js](https://nodejs.org/) — Entorno de ejecución de JavaScript
- [JavaScript (ES Modules)](https://developer.mozilla.org/es/docs/Web/JavaScript/Guide/Modules) — Lenguaje principal (`"type": "module"`)

---

## 📁 Estructura del proyecto

```
├── index.js        # Lógica principal de la aplicación
├── package.json    # Configuración del proyecto y scripts
└── README.md
```

---

## ⚙️ Instalación y uso

### Prerrequisitos

- [Node.js](https://nodejs.org/) instalado (versión 16 o superior recomendada)

### Pasos

1. **Clonar el repositorio**

```bash
git clone https://github.com/Franconext/Proyecto-pre-entrega.git
cd Proyecto-pre-entrega
```

2. **Ejecutar el proyecto**

```bash
npm start
```

> Esto corre `node index.js` directamente, sin necesidad de instalar dependencias.

---

## 📜 Scripts disponibles

| Script | Descripción |
|--------|-------------|
| `npm start` | Ejecuta el archivo `index.js` con Node.js |

## 📚 Contexto del proyecto

Este proyecto es una **pre-entrega académica** que pone en práctica conceptos fundamentales de JavaScript, como:

- Manejo de datos con arrays y objetos
- Funciones y lógica de negocio
- Uso de ES Modules (`import` / `export`)
- Ejecución de scripts con Node.js
